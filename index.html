Multiclass Classification of UCI HAR Dataset

This project focuses on optimizing a multiclass classifier using Forward-Backward and ADMM algorithms.

Dataset: UCI HAR

Optimization Formulation

\[ \min_{x \in \mathbb{R}^{(M+1)K}} g(x) + \lambda h(x) \]

Results

Method Accuracy
Forward-Backward 89.75%
ADMM 88.70%
