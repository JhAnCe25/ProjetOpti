Human Activity Recognition using Smartphones

Project Overview

This project implements and compares optimization algorithms for multiclass classification on the UCI Human Activity Recognition dataset. We explore Forward-Backward splitting and ADMM methods with L1 regularization.

Optimization Formulation

Main Problem

\[ \min_{x \in \mathbb{R}^{(M+1)K}} g(x) + \lambda h(x) \]

Loss Function \(h(x)\):

\[ h(x) = \sum_{\ell=1}^{L} \log \left( 1 + \sum_{k \neq \ell} \exp [\mu_\ell + \varphi(u_\ell)^T (x^{(k)} - x^{(z_\ell)})] \right) \]

Regularization \(g(x)\):

\[ g(x) = \sum_{k=1}^{K} \| w^{(k)} \|_1 \]

ADMM Reformulation

\[ \min_{x,z} \lambda h(x) + g(z) \quad \text{s.t.} \quad x - z = 0 \]

Augmented Lagrangian:

\[ \mathcal{L}_{\rho}(x, z, u) = \lambda h(x) + g(z) + u^T(x - z) + \frac{\rho}{2}\|x - z\|_2^2 \]

Methods

Forward-Backward Algorithm

Solves problems of the form:

\(\min_x f(x) + g(x)\)

  • Step 1: Gradient descent on \(f(x)\)
  • Step 2: Proximal operator on \(g(x)\)
  • Parameters: \(\tau < \frac{2}{L_f}\)

ADMM Algorithm

Alternating Direction Method of Multipliers:

  • Step 1: Update \(x\) (smooth minimization)
  • Step 2: Update \(z\) (proximal operator)
  • Step 3: Update multiplier \(u\)
  • Parameter: \(\rho > 0\)
